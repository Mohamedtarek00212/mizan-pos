# Mizan POS — خطة اختبار قبول المنتج (UAT)

## الهدف وقواعد النجاح

ينفذ الاختبار على نسخة مرشحة للإطلاق، بقاعدة بيانات تجريبية وأجهزة العميل
الفعلية. ينجح الإصدار عند مرور الحالات الحرجة كلها، وعدم وجود عيوب حرجة أو
عالية، وتوقيع ممثل التشغيل والمالك على النتيجة.

## بوابة الاختبار الآلي

شغّل `./ops/release-check.sh`. يجب أن تنجح اختبارات وبناء Backend وFrontend
وDesktop بالكامل، ثم احفظ سجل التنفيذ مع رقم الإصدار وSHA-256 للمثبت.

## سيناريوهات القبول

| المجال | السيناريو المطلوب | النتيجة المتوقعة |
|---|---|---|
| الدخول والصلاحيات | الدخول بكل دور ومحاولة فتح شاشة غير مصرح بها | الدخول الصحيح فقط، ومنع الشاشة والفعل غير المصرح |
| الخزينة | فتح وردية ثم محاولة فتحها ثانية ثم إغلاقها بفائض/عجز | منع التكرار وتسجيل المتوقع والمعدود والفرق والمغلق |
| البيع | بحث وباركود وتعديل كمية وتعليق واستكمال وإلغاء | حساب صحيح وعدم بيع مخزون غير متاح وسجل تدقيق كامل |
| الدفع | نقدي وبطاقة ومختلط وحالة بطاقة غامضة | لا ازدواج دفع، ولا اكتمال قبل تحصيل الإجمالي |
| الأجهزة | طباعة وإعادة طباعة، ماسح، درج نقدي | الأجهزة الفعلية تعمل، والفشل يعطي إجراء استرداد واضح |
| الخصومات | خصم داخل الحد وآخر يتطلب مديرًا | تطبيق الحد الصحيح وربط اعتماد المدير بالعملية |
| المرتجعات | بإيصال وبدونه واسترداد نقد/بطاقة | منع تجاوز الكمية، حساب الضريبة/الخصم وتحديث المخزون |
| المخزون | توريد وتسوية موجبة/سالبة وحركة وتنبيه | رصيد وحركة ذريّان وصلاحيات صحيحة وتنبيهات دقيقة |
| التقارير | المبيعات والتسوية والمخزون والمرتجعات بفلاتر | الأرقام تطابق العمليات المصدرية والتوقيت المحلي |
| اللغات والشاشات | العربية والإنجليزية، سطح مكتب ومقاس صغير | RTL/LTR صحيحان، لا قص أو تمرير أفقي معيق |
| الانقطاع | قطع API أثناء سلة غير مدفوعة ثم إعادة الاتصال | رسالة واضحة، لا دفع مكرر، والاستئناف الآمن |
| النسخ الاحتياطي | نسخة ثم استعادة في قاعدة معزولة | checksum صحيح، readiness ناجح، وتطابق العينات |
| التثبيت | تثبيت/تشغيل/ترقية/إزالة على Windows وmacOS | توقيع موثوق، حفظ الإعدادات، وعدم فقد بيانات الخادم |

## سجل العيوب والتوقيع

لكل عيب: رقم، السيناريو، خطوات الإعادة، المتوقع/الفعلي، صورة أو سجل، الشدة،
المسؤول، والإصدار الذي تحقق منه. التوقيع النهائي يتضمن اسم ممثل العميل، ممثل
التطوير، التاريخ، الإصدار، الأجهزة المختبرة، وقرار: قبول / قبول مشروط / رفض.
